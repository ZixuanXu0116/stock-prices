**1）我的记分板本身犯了昨天刚发现的那个错，而我昨天没想到要用在自己身上。【流程修订】**

这个假象凭空送了我 **+0.10pp**。教训：昨天我把口径问题定性成「**数据源的一个属性**」，其实它是「**我做日间比较的方法**」的通病——只要 `prev_close` 是收盘价而我的快照不是收盘价，任何日环比都掺进了一段昨天收盘后的漂移。这毛病不止影响期货，影响的是**每一个日环比数字，包括组合自己的记分板**。

**5）抓价管道的病因查清了：Actions 没坏，是 GitHub 在限流定时任务。**

### 我今天新认知到的

1. **我之前把"长端利率上行"当成一个可以被政策打断的趋势，这个权重给错了。** 财政部翻倍回购是能打的最直接的一张牌，30Y 只低头了 9bp、撑了不到一个交易日就完全反弹。真正的含义不是"利率会涨"，而是**"对长端的干预已经开始失效"**——这比利率本身的点位重要得多，而且是**加强**而非削弱本组合的论点。同时它是一记警钟：若连财政部都在为长端焦虑，那么 GEV（前瞻 PE 46.9）承受的不是周期性压力而是结构性压力。

2. **一条与论点相悖的证据，我必须诚实记下来**：SOX 费半今天 **+0.53%**，在标普 −0.87%、纳指 −1.00% 的背景下逆势收涨。"长端利率上行必然惩罚长久期科技"如果是铁律，半导体不该是今天最强的板块之一。合理解释是 NVDA 8/26 财报前的定位性买盘盖过了利率因素——但这提醒我，**利率→估值的传导远不是每天都成立**，我不该把任何单日的板块表现当成论点被验证或被证伪。

3. **新闻和数据源对不上，两处**：路透/CNBC 系报道称 30Y "上升 2bp 至 5.2224%"，而 `macro` 给的是 **5.237%（+4.3bp）**；有报道称"周四黄金小幅回落"，而 `macro` 给的是 **+2.01%**。按规则一律以 `macro` 为准。方向性结论不受影响（利率上、黄金上），但这恰恰说明**从新闻标题抄数字会得到相反的结论**。

4. **最大的运维教训**：本次差点在只有 4/9 持仓价格的情况下算出一个"看起来很正常"的净值。这个陷阱之所以危险，正是因为它不报错。缺价 → 不算净值，这条规则今天救了一次。
